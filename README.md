## Overview

**Portfolio Tracker** is a Home Assistant custom integration for tracking stocks, ETFs, and crypto with live Yahoo Finance prices (no API key), multi-currency FX, dividend calendar, retirement forecasts, Top Movers, and a native Lovelace card.

> Full README was restored after an accidental Property Bridge upload. See the repository for complete documentation, dashboard samples, and `custom_components/portfolio_tracker`.
