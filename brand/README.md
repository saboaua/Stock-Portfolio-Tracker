# Property Bridge brand assets

| File | Size | Use |
|------|------|-----|
| `icon.png` | 256×256 | Integration icon (HACS / HA brands) |
| `logo.png` | 512×512 | Square logo (README, social) |
| `logo@2x.png` | 512×256 | Wide banner |
| `logo-small.png` | 256×128 | Compact wide mark |

## Home Assistant brands repo

To show the icon in Home Assistant’s UI, open a PR against  
[home-assistant/brands](https://github.com/home-assistant/brands) with:

```text
custom_integrations/property_bridge/icon.png
custom_integrations/property_bridge/logo.png
```

Use `icon.png` and `logo.png` from this folder.
